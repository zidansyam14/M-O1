⌨️ Keyboard Research Lab

A consent-based browser experiment for studying keyboard timing and physical key usage. This version stores key codes and timing only, never the characters you type.

Before you start

Recording begins only after you press Start experiment. While recording, this page observes keyboard events received by this webpage. Do not enter passwords, private messages, or other sensitive information. Data stays in this browser until you export it.

Research ID: an anonymous label is generated locally and can be changed.
